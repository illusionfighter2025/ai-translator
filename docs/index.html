安装步骤

四步，让翻译住进浏览器

无需注册，无需付费，几分钟即可上手。

1

下载插件

从源码仓库获取插件文件夹，解压到本地任意位置。

2

打开扩展页

在浏览器地址栏输入 edge://extensions 或 chrome://extensions。

3

开启开发者模式

打开右上角「开发者模式」开关，点击「加载解压缩的扩展」。

4

配置 API Key

点击插件图标，在弹窗填入 API Key、Base URL 与模型，保存即可。

💡
兼容哪些模型？

凡兼容 OpenAI 协议的接口皆可使用——DeepSeek、OpenAI、OpenRouter、本地 Ollama 等。在管理面板中切换源 / 目标语言，并查看 Token 消耗与翻译历史。

常见问题

你可能想问

插件是免费的吗？

完全免费且开源。你只需自备一个兼容 OpenAI 协议的 API Key，翻译产生的费用由你选择的模型供应商按其定价收取。

我的 API Key 安全吗？

密钥仅保存在你本地的浏览器存储（chrome.storage）中，不会上传到任何第三方服务器，也不会离开你的设备。

支持哪些浏览器？

基于 Manifest V3 开发，兼容 Microsoft Edge、Google Chrome 及其他 Chromium 内核浏览器。

翻译后还能看原文吗？

可以。再次点击「翻译页面」按钮或按 Alt + T 即可一键还原原文，随时中英对照。
